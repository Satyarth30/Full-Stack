Bash Commands I Have Learnt

1. touch

File creation

The touch command creates a new, empty file. If the file already exists, it simplyupdates the file's last-modified timestamp instead of changing its content. Its one of the simplest ways to create a new file directly from the terminal.

Syntax: touch filename

Example: touch notes.txt

Output: No output - the file notes.txt is created.

2. mkdir

Folder creation

The mkdir command creates a new, empty folder (directory) at the location you specify.

Syntax: mkdir foldername

Example: mkdir project

Output: No output - the folder project is created.

3. cd

Changing directory

The cd command changes the current working directory,moving you into a differnt folder in the terminal.

Syntax: cd foldername

Example: cd project

Output: The terminal moves inside the project folder.
